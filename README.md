# Arc Raiders Loot Tool

This is a tool for players of the game Arc Raiders to keep track of their loot. It provides a simple interface to browse and search through a database of in-game items.

## Features

*   **Loot Database:** A comprehensive database of items found in Arc Raiders.
*   **Search:** Quickly find items by name.
*   **Item Status:** Each item is categorized with a status:
    *   **KEEP:** Items that are valuable and should be kept.
    *   **SELL:** Items that can be sold for in-game currency.
    *   **RECYCLE:** Items that can be broken down for crafting materials.
*   **Details:** Each item includes a reason for its status and its location in the game.
